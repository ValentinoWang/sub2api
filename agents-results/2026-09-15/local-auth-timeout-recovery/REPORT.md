## 复现与修复

| 问题 | 修复前复现 | 修复行为 |
| --- | --- | --- |
| HTTP超时分类 | 真实loopback HTTP服务拖延响应，API客户端输出 Network error | 分别返回 REQUEST_TIMEOUT 和 NETWORK_ERROR，并给出中文/英文提示 |
| 临时刷新失败 | token refresh返回503或429后有效凭据被清除 | 临时失败保留会话；明确400/401/403拒绝仍退出 |
| JWT依赖失败 | 仓库读取deadline/依赖异常被转成401 USER_NOT_FOUND | 真实不存在仍401，依赖故障503，不冒充身份失效 |
| Redis截止时间 | net.Pipe伪RESP服务不返回GET，100毫秒调用时限仍等2.001秒socket超时 | 启用context时限后约149毫秒返回；无时限调用不会自动获得预算 |
| 活跃时间辅助更新 | 阻塞仓库使真实Gin认证链超过1.5秒仍进不了业务handler；取消等待者也无法退出 | 每个调用最多等1秒；Gin链约1.01秒进入handler并返回200；同用户取消等待者及时退出 |

HTTP复现使用动态loopback端口、合成凭据和100毫秒测试时限，复用真实Axios与应用拦截器；没有让真实后端停顿。测试验证兑换请求只发一次，不自动重发结果未知的写请求。
