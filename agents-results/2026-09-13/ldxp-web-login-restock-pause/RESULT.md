## 保留边界

- 这是普通兑换码管理生成的手工批次，未伪造补货服务自动批次关联。手工逐张核对通过，不等于内置自动库存身份核验通过。
- 后端持续补货尚未保存获授权的商户网页登录凭据；浏览器登录不会自动转授后端。没有确认官方长期 API Token 发放入口，没有从隐藏浏览器存储提取会话。
- 重新授权提醒目前是管理员工具页中的持续提示；没有创建短信、邮件或后台通知自动化。
- 真实验证覆盖此次正式 ¥5→$5 商品；未完成 dev 的真实购买、真实登录失效演练、持续自动补货验收、真实退款或每日独立结算账单核对。没有签署人工 PASS，未通过自动开售七项门禁。
