# 多面额购买与 Chrome 补货界面范围

## 产品与角色

购买者选择“5元额度”“10元额度”“20元额度”“50元额度”“100元额度”，人民币售价分别对应美元余额 5、10、20、50、100 元。每个选择只前往对应小铺商品，发货说明引导返回购买页兑换。业务管理员维护商品、授权设备及补货；测试与正式环境各自呈现商品归属和库存。

## 页面与状态

`frontend/src/components/payment/LiandongRechargePanel.vue` 负责面额选择、外部购买和返回兑换；`liandongPurchase.ts` 解析商品入口。额度价格与到账币种必须清晰，操作失败不伪装为成功。保留兑换中心与原生在线支付既有入口和行为。

`frontend/src/components/admin/liandong/ChromeRestockPanel.vue` 展示补货开关、商品映射、设备、最后检查与暂停信息。销售入口是否开放与自动补货是否开启分开表达。库存未知显示未知，不显示零；数量相等不意味着每份发货内容均已核验。设备绑定秘密只在专门的一次性展示区域提供，不用于截图或普通记录。

扩展显示站点、商品、库存、开始／暂停及待处理原因。检查库存与开始补货为不同动作。登录恢复、重新打开浏览器或仅检查库存后仍保持暂停，须完成核验再手动开始；不确定上传不得鼓励重复发货。
