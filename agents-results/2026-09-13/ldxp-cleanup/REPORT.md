# 小铺补货精简记录

范围：仅小铺补货模块、Chrome 插件及相关开发内容。未发布生产，未替换本地或生产容器，未改真实商品库存、设备凭据或数据库记录。

## 已删除

- 旧管理员工具页面的运行时安装、商户 Token、远程商品同步、预览/执行、任务历史与导出操作，及其前端 API 客户端和独占翻译。
- 旧 `/admin/tools/ldxp` 下的安装、配置、商品与任务接口注册。当前管理入口只保留 `/browser/*`；旧地址的请求验证为 404。
- Go 工具安装器、专属配置项及 Wire 注入；Docker 的独立工具构建阶段、资产复制与安装环境变量。
- `tools/ldxp-toolkit` 独立 CLI 源码及约 6 MB 的旧 dist 编译产物。
- Chrome 重复弹窗页面和样式；旧单商品绑定、独立检查/开始/暂停消息入口。点击扩展图标直接打开唯一设置页。
- 后台逐商品库存目标与批次数量输入；商品新增默认目标 999、单批 20，现有商品参数保留，目标统一在插件设置。
- 旧开发文档中 50,000 库存、CLI、安装器和任务页面操作说明，改为当前流程与代码入口。

## 保留

- 两站分别授权、默认选择全部合格商品、一键配对并维持每种额度 999 张、暂停全部和异常核验。
- 现有绑定、设备凭据复用、原批次和库存记录，逐码身份核验、上传不确定暂停及重复执行保护。
- 在线支付、充值、兑换、权益退款、结算核对以及仍由支付管理和历史库存接口依赖的共享服务。
- 数据库迁移、历史批次与真实兑换码、人工验收记录、旧机器证据。没有清空本地自用数据或全局开发缓存。
