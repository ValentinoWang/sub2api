# 双站点与多额度批量绑定

本次完成扩展本地实现和桌面文件更新；真实浏览器重新加载、真实两站绑定读回尚未完成。生产代码、服务器和小铺库存没有在本次操作中变更。

## 行为

- 本地 `http://127.0.0.1:8080`、生产 `https://ai.rest2build.lol` 同页显示，凭据按站点保存和复用。
- 读取后默认全选该设备授权范围内已启用、无绑定冲突的商品，支持一次保存两个站点全部额度，也可手动减少选择。
- 保存前逐站读取服务端配置校验设备和商品；所有选择通过后一次写入扩展 storage.local。第二站失败不会保存第一站或新凭据。
- 重复保存保留旧绑定运行状态、库存及待处理批次，新绑定默认暂停；同一商户商品不能绑定到其他站点或设备。
- 旧版商品绑定中的凭据按同站点唯一设备复用，不返回明文到表单或快照。存在多个不同旧凭据时，不猜测设备。
- 取消勾选不删除旧绑定；移除仍要求暂停且无待处理批次。后台任务结束后，绑定页控件通过存储变更恢复可用。
