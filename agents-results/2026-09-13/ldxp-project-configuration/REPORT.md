# 个人插件项目内配置

按本次要求，源码、站点地址配置、使用说明均以 `tools/ldxp-browser-extension/` 为维护入口。本次没有继续更新桌面副本，也没有操作真实浏览器的安装、绑定或补货。

- `config.js` 集中维护本地与生产地址、名称、管理链接及个人项目路径，绑定界面和后台站点校验共用站点配置。
- 插件管理页直接显示项目目录、各配置保存位置、两站设备凭据获取方式、默认全选、统一保存和补货步骤，并提供两站管理入口。
- 商品映射继续从各站授权设备配置读取，真实设备凭据继续保存在 Chrome 扩展本地存储；没有写进源码或打包文件。
- README 写明从项目目录加载、更新操作，以及从旧桌面目录换到项目目录时扩展身份与存储不会自动迁移的边界。
- 项目内 `frontend/public/assets/ldxp-browser-extension.zip` 已重新生成，打包白名单包含新的配置模块。

验证：45 项现有测试通过；独立 Chromium 中项目路径、管理链接与说明可见，默认双站全选、批量保存与重开验证通过，1280/390 宽度无溢出，无页面 JavaScript 错误。浏览器使用虚构设备和商品、模拟配置读取，不是实际两站配置成功或库存验收。
