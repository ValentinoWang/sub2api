# 订阅与分组界面范围

管理员在“IP管理”（`frontend/src/views/admin/ProxiesView.vue`）导入订阅时可选择自动刷新间隔；工具栏“订阅与分组”对话框（`frontend/src/components/admin/proxy/ProxySubscriptionsPanel.vue`）列出每个订阅的格式、节点数、已用流量与到期时间、订阅说明条目、上次与下次刷新、刷新失败原因，可立即刷新或修改自动刷新间隔；分组按“订阅自带分组、用途（🎫 打票出口 / 💼 业务出口）、类型与倍率、地区”分区显示，点开可见成员的规范名称（Codex_degrade 命名格式）、住宅或机房、倍率与线路。“打票管理”（`frontend/src/views/admin/CodexHarvestView.vue`）的打票代理池可按分组一键选入或移出，代理行显示规范名称和类型标签。

复用现有对话框、按钮、标签和表格样式，桌面和窄屏均检查分组按钮可换行、成员列表可读、无横向溢出。未保存订阅地址、刷新成功、刷新失败分别有可见提示。页面与接口不显示订阅地址、分享链接和节点凭据。本文未声明视觉或人工通过，未指定外部设计稿为严格视觉权威。机器证据仅进入本任务 acceptance/。
