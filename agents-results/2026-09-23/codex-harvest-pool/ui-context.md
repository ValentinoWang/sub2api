# 打票管理界面范围

管理员在侧边栏“打票管理”（`frontend/src/views/admin/CodexHarvestView.vue`）完成打票相关的全部操作：从代理管理已有代理中勾选打票代理池并检测出口，选择速度预设或手工调整七个速度与限额数值后一次保存；查看各账号每个门控模型的门票是否可用、剩余秒数、出票代理、冷却时间和本小时请求数；对单个账号发起有次数上限的手动打票；查看并重置代理成绩；查看最近 200 条打票流水。系统设置的“Codex 设置”只保留“292 打票”开关和前往该页面的链接。

复用现有卡片、表格、标签、对话框和确认框样式，桌面和窄屏均检查表格可横向滚动、按钮可达、提示可读。打票未开启、代理池为空、代理不可用、保存失败、手动打票进行中与结束分别有可见状态。页面与接口不显示门票原文和代理密码。本文未声明视觉或人工通过，未指定外部设计稿为严格视觉权威。机器证据仅进入本任务 acceptance/。
