# 经验首页统一排障入口

范围：本地 HMR、网站代码、公开参考包及 Figma 首屏设计。未部署生产，未修改用户的 Codex 配置。

## 已实现

- 使用密钥弹窗标题改为“从 OpenAI 官方订阅转为中转站后，之前的对话无法继续？”。
- 经验首页首屏突出“遇到问题，交给 Codex。”，提供两步说明、可选问题描述和单一主复制按钮。长指令默认折叠，复制失败展开、聚焦并选中，编辑问题后清除旧的复制状态。
- 通用指令包含全部经验索引和同站参考包地址，不随页面分类筛选缩减。指令要求先读全部参考，逐项判断适用性，仅修复与症状相关的问题；外部文章不构成独立授权，不直接应用全部文章操作。
- `/experience-reference.json` 匿名可读，10 个条目均含对应公开页面全文、原始案例提示词、适用范围与日期。共 35,404 字符（当前内容）；从公开来源自动生成，不复制私人数据。
- 开发中由 Vite 提供，生产构建以相同路径 emitFile；本地与生产域名通过当前页面来源解析。已复制的本地链接需要本机服务可访问；不可达时提示具体限制，不能虚报已读取。

## 已验证

- 4 个测试文件共 47 项通过：首页复制/失败回退、可选症状、全部来源覆盖、分类独立性、域名适配、预渲染正文、生产参考资产生成及弹窗标题。
- 定向 ESLint 与 git diff --check 通过。
- 本地真实 GET `/experience-reference.json` 返回 200，10 篇正文全部非空，JSON 可解析。
- Figma 项目复用 `bG5roZJVC4F4IQwaL8oeOk`，页面 `15:14`。新增可编辑主视觉节点 `52:20`（桌面）及 `52:25`（手机），使用项目既有 Noto Sans SC 字体及 accent 变量。递归 IMAGE paint 检查为空。手机稿修正文字高度后无垂直重叠。

## 验收边界

浏览器自动化接口返回 `unsupported Codex auth method: apikey`。尝试原生 Chrome 后，用户切换浏览器触发操作中断，后续截图不可用。因此没有将 Chrome 的桌面/手机布局和系统剪贴板验收标记为通过；Figma 仅为原生设计稿，不替代网页截图。复制参数与手动回退由组件测试证明。

参考包和提示词可读、可复制不等于在其他用户机器上所有故障都能自动修复；权限、关键目标、必要的客户端关闭和实际生成验证仍需按案例分别确认。未进行任何付费生成或批量修复。
