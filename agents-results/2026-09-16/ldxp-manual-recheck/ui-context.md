# 本地立即检查界面范围

业务管理员在 `frontend/src/components/admin/liandong/ChromeRestockPanel.vue` 完成商户验证后请求立即检查。按钮、等待状态和结果提示必须区分“已提交”与“已检查”；失败保留暂停，刷新读取实际结果。页面删除可选 Chrome 扩展入口、安装引导与下载入口，保留本次仍需使用的商品、库存和补货状态。商品映射移到页面底部，默认折叠，点击后展开；折叠控件仅管理映射显示，不改动已保存商品或补货状态。刷新后恢复默认折叠。

复用现有布局及状态组件，桌面和窄屏均检查按钮可达、提示可读和无横向溢出。等待、请求失败、检查失败、成功与仍暂停分别保留本地浏览器观察；只读截图不能代替检查链路证明。本文未声明视觉或人工通过，未指定外部设计稿为严格视觉权威。机器证据仅进入本任务 acceptance/。
