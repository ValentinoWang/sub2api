# 本地补货专用窗口与人工验证界面范围

业务管理员从 `http://127.0.0.1:4174/admin/tools/ldxp` 进入本机助手 `http://127.0.0.1:52401/`，点击“打开补货专用窗口”。助手只唤起真实补货执行器的专用窗口，不展示登录资料输入框，不把普通商户网页当作专用窗口。用户在专用窗口亲自登录并完成人工验证，返回管理页点击“我已完成验证，立即检查”。

等待、检查失败、库存未知、人工暂停与恢复须清楚区分。只有同一会话授权和全部库存核对成功才恢复既有 999 目标；助手打开成功不等于检查通过。商品映射继续位于管理页底部，默认折叠，点击展开；不扩大其他页面改动。

浏览器证据应覆盖助手、专用窗口指引、管理页等待及结果和底部映射。实际商户登录与人工验证仍待人工，本文不宣称视觉或业务验收通过；未指定严格外部视觉权威。截图及机器结果只进入本任务 acceptance/，不得包含凭据、完整卡密或敏感会话资料。
