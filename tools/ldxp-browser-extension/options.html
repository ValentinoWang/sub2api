小铺补货助手

自动维持库存

配对商品，设置库存数量。卖出后自动补足，不用逐项检查和开始。

只需设置一次

首次填写两站的补货凭据，读取商品后默认全选。设置每种额度要保持的库存，点击「保存并自动补货」；插件会自动核对商品和库存，分批补足缺口。

打开并登录小铺商户页

Chrome 在线且小铺商户页保持登录时，每分钟检查一次。首次补足 999 张需要多轮上传；登录失效或库存异常时暂停并显示原因。

安装、更新与配置文件位置

插件源码、两站地址配置和使用说明统一放在项目目录：

config.js 保存两个站点的地址与管理入口，README.md 保存完整说明。Chrome「加载已解压的扩展程序」选择上述目录，直接维护这一份源码。

更新后看不到「只需设置一次」：在 Chrome 地址栏输入 chrome://extensions，确认加载的是上面的项目目录，点击该扩展的重新加载按钮，再关闭旧绑定页并重新打开。

设备凭据是以 ldxpd_ 开头的补货专用密钥，只保存在当前 Chrome 扩展中；不填写管理员密钥或小铺登录 Token。本地使用测试商品，生产使用正式商品。

如果之前从桌面目录加载了插件

更换加载目录可能生成另一个扩展身份，旧凭据与绑定不会自动迁移。切换时先暂停旧扩展补货，在项目目录这份插件中重新保存两站绑定。以后更新项目代码，在 Chrome 扩展管理页重新加载，再重开本页即可。
