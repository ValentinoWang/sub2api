Claude Code 使用经验 / ERR-004

Claude Code 每次执行都要确认，怎样默认跳过？

适用：可信的本机开发环境 · 更新：2026-09-13

01

问题说明

Claude Code 在读取文件、修改代码或运行命令前反复要求确认，连续开发经常被打断。目标是在可信的本机项目中默认跳过逐项确认，同时保留恢复普通确认模式的入口。

风险提示：跳过确认后，Claude Code 可以直接执行文件修改和命令。陌生仓库、未经审查的脚本、生产凭证目录或范围不明确的任务，应继续使用普通确认模式。

02

解决方案

  1. 保留现有用户配置，把 permissions.defaultMode 设置为 bypassPermissions。
  2. 把 skipDangerousModePermissionPrompt 设置为 true。
  3. 关闭旧会话并启动新会话验证。需要单次恢复确认模式时，使用 claude --permission-mode manual。

03

原因、验证与注意事项

为什么两个设置都需要？

defaultMode 决定新会话采用的默认权限模式；启动确认开关决定进入高权限模式时是否再次提醒。只改其中一个，体验可能仍然包含确认步骤。

怎样确认已经生效？

验证配置语法后，启动一个全新会话，用只读操作和普通项目命令确认。不要用删除文件、修改系统设置或访问生产数据来测试。

边界

跳过确认只改变交互方式，不扩大任务授权。遇到范围不清楚的操作，仍应停下来确认。
