# Codex 本地旧对话接续：技术交付记录

本文件保存开发、构建和发布边界；人类实际操作和签字仅记录在 `docs/human-acceptance/CODEX_SESSION_MIGRATION.md`。

工具版本为 `1.0.0`，站点对外发布标签为 `0.2.1`，两者不互相替代。交付候选包含离线工具包、提示词文本和 JSON 校验清单，三者由 `tools/build_codex_session_migrate.py` 共同生成或复制。

本次候选已完成本地 Python 事务夹具、前端类型与经验页测试、前端生产构建、离线包解压和 SHA-256 对照、Go 嵌入下载测试，以及本地 HMR 的桌面和移动页面检查。该记录不表示生产切换或人类验收已完成。

本机验证必须分别记录：结构化 JSONL/SQLite 迁移、备份失败零写入、中断恢复或精准回滚、工具包解包校验，以及真实客户端重开同一任务后的接续结果。站点嵌入验证必须确认经验页、下载字节、清单摘要和未知下载路径失败；开发服务器预览不能替代嵌入或线上回读。

没有三个系统的真实客户端接续记录和人类验收签字时，公开工具仍为待验收。发布或回滚必须把页面、下载包和清单作为同一候选处理。
