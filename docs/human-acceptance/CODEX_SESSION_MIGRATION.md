# Codex 本地旧对话接续验收

状态：待验收

## 验收范围

本清单检查从本站经验页获取离线工具或提示词后，使用者是否能在自己的设备上安全处理切换接入造成的本机旧对话 provider 关联问题。每个操作系统应单独填写，不以另一个系统的结果替代。

不在范围内：ChatGPT 网页历史、云端记忆、正在进行的连接或工具调用、账号订阅权益、服务端 Redis 状态，以及未知客户端格式。

## 开始前

验收人准备一台有可恢复测试旧任务的设备。旧任务应包含一条可识别但不敏感的测试事实。准备一个目标接入配置；不得在本清单或截图中记录完整 API Key、认证文件、私人消息或用户真实路径。

## 阻塞条件

下载内容无法打开、工具提示目标或数据目录不明确、备份验证失败、旧任务仍无法打开、迁移后丢失测试事实、无法追加新交流，或需处理本清单范围外的历史时，本次该系统验收为阻塞。
